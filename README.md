# QBLA NOVE — sitio web oficial (prototipo v1)

Sitio web estático, adaptable y sin costes de hosting ni dependencias. Archivos principales: `index.html`, `styles.css`, `script.js`.

## Publicación gratuita en GitHub Pages

1. Inicia sesión en GitHub. Para tener la dirección **qblanove.github.io**, la cuenta de GitHub debe llamarse **qblanove** (si está disponible) y el repositorio público debe llamarse exactamente **qblanove.github.io**.
2. Crea ese repositorio público (o usa otro nombre de repositorio; en ese caso la dirección será `USUARIO.github.io/REPOSITORIO/`).
3. Sube **el contenido de esta carpeta**, incluidos `index.html`, `styles.css`, `script.js` y `assets/` a la raíz del repositorio. No subas solamente el archivo ZIP.
4. En el repositorio, ve a **Settings → Pages**. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
5. La URL estará disponible una vez que GitHub complete el despliegue. GitHub Pages publica el contenido como sitio web público.

## Imágenes oficiales aún pendientes

**No se han inventado ni recreado los símbolos oficiales.** La web incluye espacios reservados. Para mostrar los originales validados, coloca estos archivos PNG dentro de `assets/`:

- `escudo-oficial.png` — **última versión heráldica aprobada**, con yelmo y lambrequines, molino, salvado y rueda dentada de nueve dientes.
- `bandera-oficial.png` — **bandera oficial** con la cruz desplazada hacia el asta y el escudo en la intersección.

Al cargar los PNG, la web sustituirá los espacios reservados automáticamente. Las letras QN son un monograma tipográfico **provisional, no el escudo oficial**. Los elementos decorativos no son reproducciones heráldicas.

## Privacidad y contenidos

No se han incluido dirección postal completa, teléfono particular, nombres de familiares ni fotografías de personas. Los eventos se mencionan en términos generales y no constituyen invitaciones públicas. Antes de publicar fotografías se deben obtener los permisos correspondientes. No existe zona privada en esta versión: todo lo publicado en GitHub Pages es **público**. Una futura zona restringida necesitaría un servicio de autenticación y almacenamiento con control de acceso, no solamente HTML estático.

## Ediciones

- Textos y secciones: edita `index.html`.
- Diseño, tamaños y colores: edita `styles.css`.
- Menú móvil, animaciones e imágenes opcionales: `script.js`.
- La web no utiliza cookies de seguimiento, analíticas ni fuentes de terceros.
